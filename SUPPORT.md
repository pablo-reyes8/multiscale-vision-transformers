# Support

Use the appropriate public channel for non-sensitive questions:

- **Bug or regression:** open a bug report with a minimal reproduction.
- **Feature proposal:** open a feature request describing the use case.
- **Usage question:** start a GitHub Discussion if Discussions are enabled;
  otherwise open an issue marked as a question.
- **Security concern:** follow [SECURITY.md](SECURITY.md), never a public issue.

Please include the package version, Python/PyTorch versions, operating system,
model name, configuration and complete error traceback when asking for help.
